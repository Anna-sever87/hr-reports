# Автоматический отчёт по подбору сотрудников

Учебный проект Анны Пановой. Модуль 9, урок 2.

Приложение на Python с окном tkinter создаёт случайные показатели воронки подбора и записывает оформленный отчёт на новый лист существующей Google Таблицы. Данные вымышленные. Из рабочей системы сведения не загружаются.

## Что умеет приложение

- Выбор начала и конца периода, направления и количества вакансий.
- Генерация показателей: план найма, отклики, собеседования, предложения, выходы на работу.
- Запись нового листа с заголовком, цветами, шрифтами, объединением ячеек, фильтром и итогами.
- Формулы итогов и конверсии пересчитываются в самой таблице.
- Проверка записанных итогов чтением из Google Sheets.
- Открытие созданного отчёта в браузере.

Начальная дата и конечная дата включаются в период. Случайное число откликов учитывает продолжительность периода. События внутри периода генерируются как учебная воронка: собеседований не больше откликов, предложений не больше собеседований, выходов не больше предложений и плана найма. Это упрощённая модель, а не анализ реальных переходов кандидатов между периодами.

## Структура проекта

`google_sheets.py` — класс `GoogleSheets`: чтение, добавление, изменение и очистка данных; создание и удаление листов; пакетное оформление. Точка входа выводит названия листов и значения первого листа в консоль. Модуль можно подключить в другом приложении.

`report_generator.py` — окно tkinter, генерация случайных данных и подготовка отчёта. Запись выполняется в фоновом потоке, окно остаётся доступным. Пакет данных и оформления отправляется одним атомарным запросом Google Sheets API.

`config.example.json` — пример настроек. `config.local.json` — личная рабочая конфигурация, в архив не входит.

`.secrets/service-account.json` — локальный ключ сервисного аккаунта. В GitHub и архив его включать нельзя.

`start.cmd` — запуск двойным щелчком в Windows после установки зависимостей.

`package_homework.py` — сборка ZIP по явному списку файлов, без ключа, личных настроек и виртуального окружения. Скриншоты прикрепляются к ДЗ отдельно.

## Первый запуск на другом компьютере

Нужны Windows, Python 3.12 или новее с tkinter, интернет и VS Code с расширениями Python и Python Debugger.

1. Откройте папку `HR Reports` в VS Code.
2. В терминале создайте окружение и установите библиотеки:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-cache-dir -r requirements.txt
```

3. В Google Cloud создайте проект, включите Google Sheets API и создайте сервисный аккаунт. Роли Owner/Editor облачного проекта для доступа к конкретной таблице не нужны.
4. Скачайте JSON-ключ и сохраните его в `.secrets/service-account.json` внутри проекта.
5. Вручную создайте Google Таблицу. В её настройках доступа добавьте email сервисного аккаунта с правом Editor. Общий доступ по ссылке открывать не требуется.
6. Скопируйте `config.example.json` в `config.local.json`. Заполните `spreadsheet_id`: это часть адреса таблицы между `/d/` и `/edit`.
7. Откройте `report_generator.py`. Для запуска используйте «Выполнить» → «Запуск без отладки» (Ctrl+F5) и конфигурацию «Генератор отчётов». Либо выполните:

```powershell
.\.venv\Scripts\python.exe report_generator.py
```

8. Выберите период, направление и число вакансий. Нажмите «Сформировать отчёт», дождитесь результата и нажмите «Открыть готовый отчёт».

На подготовленном компьютере окружение и личные настройки уже находятся в папке проекта.

## Проверка модуля отдельно

```powershell
.\.venv\Scripts\python.exe google_sheets.py
```

Это только чтение: выводятся листы и значения первого листа.

## Проверки для сдачи

Автоматические проверки: `python verify_project.py` проверяет учебную модель и ограничения полей. Команда `python verify_project.py --live` дополнительно проверяет CRUD на отдельном временном листе, удаляет этот временный лист и создаёт один отчёт. Существующие листы она не меняет.

1. Сформировать отчёт за выбранный период и увидеть соответствующий новый лист в Google Таблице.
2. Проверить название периода, число вакансий, оформление, суммы и конверсию.
3. Повторить генерацию: появится новый лист, ранее созданный отчёт сохранится.
4. Ввести окончание периода раньше начала: приложение должно предложить исправить даты и не записывать отчёт.
5. Сделать скриншоты окна приложения с результатом и оформленной Google Таблицы. Проверку CRUD можно показать отдельно в консоли или по коду модуля.
6. Выполнить команду ниже и прикрепить полученный ZIP вместе со скриншотами:

```powershell
.\.venv\Scripts\python.exe package_homework.py
```

## Если возникла ошибка

- **403:** проверьте включение Google Sheets API в нужном проекте и право Editor на таблицу у email сервисного аккаунта.
- **404:** проверьте ID таблицы и доступ сервисного аккаунта к ней.
- **Нет файла ключа:** проверьте `credentials_path` в `config.local.json`.
- **Ошибка даты:** используйте формат ДД.ММ.ГГГГ, например 01.10.2026.
- **Ошибка сети:** проверьте соединение. Перед повтором откройте таблицу: запрос мог успеть выполниться, даже если подтверждение не пришло.
- **Ключ потерян или опубликован:** удалите его в Google Cloud и создайте новый.

Google Drive API и платные ИИ-запросы для работы этого приложения не используются. VS Code используется вместо Cursor: функциональность Python-приложения соответствует заданию.
